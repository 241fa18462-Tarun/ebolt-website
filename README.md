## ✨ About eBolt

**eBolt** is an AI-powered productivity platform built with modern web technologies.

It combines a clean and responsive interface with **AI capabilities, authentication, cloud services and productivity-focused features** to create a smooth user experience.

🎯 **Goal:** Build a smart digital workspace that helps users interact, manage information and get things done more efficiently.

---

## 🚀 Features

- 🤖 **AI-Powered Chat** — Interact with an intelligent AI assistant
- 🎙️ **Voice & Audio Support** — Designed for convenient voice-based interaction
- 🔐 **User Authentication** — Secure user login and account management
- ☁️ **Firebase Integration** — Cloud-based application services
- 💬 **Interactive UI** — Clean and responsive user experience
- 📱 **Responsive Design** — Works across desktop, tablet and mobile devices
- ⚡ **Fast Performance** — Built with modern frontend technologies
- 🎨 **Modern Interface** — Simple, attractive and user-friendly design
